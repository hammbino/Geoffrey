# Your Geoffrey

A private repository that is also your assistant. It holds what Geoffrey knows
about you, in plain markdown.

## Using it

**On your computer** — open this folder in Claude Code:

```bash
cd geoffrey-<yourname>
claude
```

**On your phone** — open the Claude app, tap **Code**, pick this repository.
The session runs in the cloud and keeps going with your phone in your pocket.

**In Claude Desktop or on the web** — install the Geoffrey plugin, and connect
the Geoffrey connector for mail and calendar.

## What's in here

| | |
|---|---|
| `CLAUDE.md` | Who you are and how Geoffrey should behave |
| `memory/` | What Geoffrey has learned, one fact per file |

## It's yours

Every file here is plain text in a repository you own. Nothing is locked in a
service. To leave, take the folder.
